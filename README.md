# X-SSH

以**命令面板**为核心的极简 SSH 客户端。基于 Electron + Vue 3。

整个产品围绕一个理念:**按下 `Ctrl/Cmd+K`,一切都在这里发生** —— 连接、切换、
管理主机。没有臃肿的侧边栏,没有层层嵌套的对话框。输入 `user@host` 回车即连。

## 产品定义

- **零摩擦连接** —— 输入 `user@host`、`host:2222` 或 `user@host:22` 即可连接。
- **键盘优先** —— 所有操作都能不碰鼠标完成。
- **专注的终端** —— GPU 渲染的 xterm,没有多余的界面元素。
- **默认安静** —— 跟随系统的明暗主题、克制的配色、充足的留白。
- **安全可靠** —— 密钥/密码不出主进程,主机指纹首次即信任并持续校验。

## 功能

**连接**
- 快速连接:`user@host` / `host:端口` / `user@host:端口`,回车即连
- 命令面板(`Ctrl/Cmd+K`):模糊搜索已保存主机与操作,内联输入密码
- 已保存主机:本地持久化;密码(可选)经 Electron `safeStorage` 按设备加密
- 认证:密码 / 私钥 / SSH agent
- 已保存的密码主机若无存储密码,连接时内联提示输入(而非直接失败)
- **断线重连**:会话失败或断开后,标签内一键重连(参数保留在内存)
- **跳板机 (ProxyJump)**:通过另一台已保存主机建立隧道后再连接目标
- **本地端口转发**:连接后在本机监听端口并转发到远端(可配置多条)
- **主机分组**:保存主机时可选分组,欢迎页与命令面板按组展示
- **OpenSSH 配置导入**:从 `~/.ssh/config` 批量导入主机(含 ProxyJump/IdentityFile)

**终端**
- GPU 终端(xterm.js + WebGL),自适应尺寸
- **右键菜单**:复制 / 粘贴 / 查找 / 全选 / 清屏
- **复制粘贴快捷键**:`Ctrl+C`(有选中时复制,否则发送中断)、`Ctrl+V` 粘贴,
  以及标准的 `Ctrl+Shift+C/V`
- **终端内搜索**(`Ctrl+F` / `Ctrl+Shift+F`):上一个/下一个、区分大小写
- **字体缩放**(`Ctrl+=` / `Ctrl+-` / `Ctrl+0`),持久化且所有终端同步
- **自定义配色方案**:可选的终端配色(Nord / Dracula / Solarized / One Dark / Gruvbox / Monokai),也可跟随应用明暗主题
- **多行粘贴确认**:粘贴包含多行内容前先确认,避免误执行一串命令
- **粘贴清理**(可选/默认开):粘贴时移除 OSC/转义等终端控制序列,避免对 shell 做非预期操作

**多会话与界面**
- 多标签,带连接状态点
- **标签右键菜单**:重新连接 / 复制会话 / 关闭 / 关闭其他
- **状态栏**:当前主机、连接时长、跳板/端口转发标记、主机密钥信任态
- **主机颜色标记**:标签左侧显示保存主机的专属颜色
- **命令面板分组**:按「快速连接 / 主机 / 命令片段 / 操作」分组展示
- 日/夜主题切换按钮,终端配色同步切换,选择持久化

- **命令片段 & 通知**
- **命令片段**:在设置或命令面板新建常用命令,选中即发送到当前终端
- **桌面通知**:连接断开、文件传输完成时发送系统通知(可在设置中关闭)
- **界面语言**:简体中文 / English 可切换(设置 → 通用)

**文件与网络**
- **SFTP 文件管理器**:右侧文件抽屉,是一个轻量远程文件管理器
  - 浏览:面包屑路径导航、上级/主目录、按名称/大小/时间排序、显示修改时间
  - 传输:上传(**文件或文件夹**,选择或**拖拽**,递归)、下载;**从抽屉拖文件/文件夹到本地**;
    底部**实时进度条**;**下载断点续传**(中断后重传会从已有部分继续)
  - 操作:新建文件夹、新建文件、重命名、复制路径、删除(目录递归,删除前**自绘确认框**)
  - **打包/解压**:远程文件/文件夹一键打包成 tar.gz 下载;**上传归档后自动解压**到当前目录
  - **最近访问 & 书签**:书签菜单内嵌「最近访问」MRU 目录;可收藏常用目录
  - **本机双面板**:内嵌本机文件浏览器(大小/修改时间/新建/重命名/删除),拖拽上传与下载;支持 `Ctrl`/`Shift` 多选后一次拖拽上传多个文件
  - **在线编辑**:右键文本文件「编辑」用内置编辑器改并存回;或「用外部程序打开」,
    用系统默认或自定义编辑器编辑,**每次保存自动回传**(轮询 mtime,兼容原子保存;
    外部编辑器在命令面板中配置)
  - **右键菜单**:文件 → 下载·编辑·外部打开·复制路径·重命名·删除;
    空白处 → 新建文件夹·新建文件·上传文件·上传文件夹·刷新

**安全**
- **主机密钥 TOFU 校验**:首次连接记录服务器 SHA-256 指纹到 `known_hosts.json`;
  再次连接若指纹变更则中止并醒目告警(疑似中间人)。确认服务器已重装时,可一键
  「信任新密钥并重连」。
- **已知主机管理**:设置 →「安全」页可查看并删除已记录的主机密钥条目
- **加密私钥**:支持带 passphrase 的私钥,可选择在本机加密保存 passphrase。

## 开发

```bash
npm install
npm run dev        # electron-vite 开发模式（HMR）
```

## 构建

```bash
npm run typecheck  # tsc（主进程）+ vue-tsc（渲染层）
npm run build      # 打包到 ./out
npm run test       # Vitest 单元测试
npm run lint:i18n  # 校验 zh/en 键对称、占位符与缺失静态键
npm start          # 预览生产构建
```

## 架构

```
src/
  shared/    类型 + IPC 通道名（各层共用）
  main/      Electron 主进程
    ssh.ts         SshManager —— 每会话一个 ssh2 Client + shell 通道
    store.ts       HostStore —— hosts.json + 加密的 secrets.bin
    knownHosts.ts  KnownHosts —— known_hosts.json（主机指纹 TOFU）
    index.ts       窗口 + IPC 装配
  preload/   contextBridge → window.api（类型安全）
  renderer/  Vue 3 应用
    stores/sessions.ts   Pinia：标签、主机、面板状态
    composables/         theme（明暗）、fontSize（字号）
    components/          TerminalView、CommandPalette、HostEditor、TabBar
    lib/                 模糊匹配、快速连接解析
```

SSH 逻辑位于主进程(Node 的 `ssh2`)。按键 渲染层 → IPC → `stream.write`;
服务器输出 `stream.data` → IPC → xterm。渲染层不直接接触网络或文件系统。

### 说明

- 私钥与已保存密码永不离开主进程;渲染层只传 `hostId`,由主进程解析密钥。
- 若 GPU 进程不可用(部分远程桌面/老旧驱动),用 `--disable-gpu` 启动;应用也会
  在渲染进程崩溃时自动重载一次。
