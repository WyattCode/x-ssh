# Android 更新日志

只记 `mobile/android` 的变化(桌面版见仓库根目录的 `CHANGELOG.md`)。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/),版本号遵循语义化版本。
标签格式 `android-vMAJOR.MINOR.PATCH`(不以 `v` 开头,不会触发桌面端 CI 的标签构建)。

## [Unreleased]

### Fixed
- 平板侧栏:键盘上下键把选中项移出可见区时,列表会跟着滚过去(原来要自己划一下才看得到高亮)。

## [0.3.0] - 2026-11-25

`.so` 与 0.2.2 相同,没有 Rust 核心的变化。**安装包从这一版起是不可调试的 release 构建**(仍用调试钥匙签名,所以能直接覆盖安装 0.2.x、数据不丢;前提同 0.2.0:装过的包得是同一把钥匙签的)。

### Added
- **主机分组**,规则和字段名与桌面版 `hostGroups.ts` 一致(`group` / `groupLocked`),两边数据互通。名字末尾带编号、至少两台共用前缀的主机(`AI TOP ATOM 0`、`AI TOP ATOM 1` …)自动成组,自动分出来的组不落盘;手动选过分组的主机不再被自动规则动。
- 平板侧栏和手机首页按分组显示:标题是「名称 数量」,点标题折叠 / 展开;搜索时一律展开;没有分组时列表和以前一样。
- 编辑主机多一行「分组」(整页编辑和平板浮层都有):自动 / 无 / 已有分组 / 新建一个名字。
- 平板键盘上下键、回车按屏幕上看到的顺序走(分组顺序,折叠的组跳过)。

### Changed
- **构建**:新增 release 构建类型(不可调试、不混淆,调试钥匙签名)。小米平板 9(120Hz,每帧约 8ms)上侧栏滑动,debug 包掉帧约 12%、99% 的帧 90 ~ 150ms,release 包基本不掉(99% 的帧 17 ~ 23ms)。
- 平板侧栏每行的长按菜单改成第一次长按才创建,并去掉每行出现时多触发的一次重组。

### Not done
- 手机首页(窄屏)的分组列表只过了编译和单测,没在真机上看过。
- 长按 / 左滑菜单里没有「移到分组」,只能在编辑页改;没有拖拽排序和手动顺序。
- 编辑页因 `FLAG_SECURE` 截不了图,分组行只用界面文字转储确认过。

## [0.2.2] - 2026-11-19

只改文案,没有功能和 Rust 核心的变化(`.so` 与 0.2.1 相同)。

### Changed
- **中文文案统一使用中文标点**(简体、繁体各 49 条):逗号、分号、冒号、问号、括号由半角改为全角,与桌面版 0.6.43 一致。英文文案不变。

## [0.2.1] - 2026-11-14

带**加固后的 Rust 核心**(0.2.0 里的 `.so` 是加固之前的)。安装包仍是 debug 签名;覆盖安装的前提同 0.2.0。**真机验证还没做完**,清单见 `mobile/HANDOVER.md` 的「Android 0.2.0 现状与交接」第五节。

### Security
- 终端核心:OSC 字符串超过 8 KiB 就取消并丢弃剩余部分(启用 `std` 的 vte 把 OSC 攒在无上限的 `Vec` 里,标题栈还会反复 clone);`feed` 切 4 KiB 小片,单元格里的组合字符最多保留 32 个;网格至少 2 列;`scroll` 参数夹取;CSI 14t 的应答把单元格像素夹到不溢出 `u16`;事件队列锁被毒化时恢复而不是每帧 panic。
- SFTP 上传:临时文件改成独占创建、名字带随机后缀、**创建时就带原文件权限位**(原来会跟着符号链接走、截断已有文件,权限要等改名后才补);目标是符号链接时先解析真实路径;覆盖时先把旧文件改成备份、新文件改名过去、成功才删备份(失败改回)。
- 凭据:核心的 `Auth` / `AuthMethod` 手写 `Debug`,密码 / 私钥文本 / 口令统一打成 `<redacted>`,不会再被日志带出去。
- 连接收尾:`Shell` 持有 `Arc<Runtime>`(销毁 `Ssh` 时不再因运行时关闭而 panic);断开 / 拆远程转发整批最多等 3 秒;`close_all_forwards` 不再握着锁等网络;`tcpip_forward` 有超时。
- 交给远端 PTY 的列 / 行夹到 2–1000 / 1–1000(原来 `as u16` 截断,70000 会变成 4464,两端网格不一致)。

### Fixed
- **一条畸形或恶意输出能让整个 App 崩掉**:UniFFI 的 panic 跨回 Kotlin 是 `InternalException`,而会话循环只接 `IllegalStateException`、所在协程没有异常处理器。现在接住所有异常、只结束那一条会话;终端对远端查询的应答(`shell.write`)与帧发布各自保护。终端网格**至少 2 列**(1 列时一个宽字符会让 Rust 终端越界)。
- 开了「用生物识别解锁」的主机,连接时第一次读 Keystore 密文不再放在主线程(进场动画期间会卡一下)。
- 连接中页面唯一的「取消」不再像一行说明文字:正文色 + 1dp 细边,看得出是个按钮。
- 连接 / 确认 / 失败页的图标光晕不再被滚动容器切成平顶(顶部留出光晕伸出的那 26dp;平板卡片自带 28dp 内边距,不多留)。

## [0.2.0] - 2026-11-08

第一个有版本说明的 Android 版本。界面整套重做,并经过多轮代码审查。**安装包是 debug 签名**(没有发布签名钥匙):已装 0.1.0 的设备用 `adb install -r` 可直接覆盖;换了电脑的 debug 签名则必须卸载重装,卸载会连同 Keystore 里的密钥一起删掉,已加密保存的密码要重新填。

### Changed
- 界面照 iOS「iPhone Duo」重做:终端风格、只有深色。折叠屏内屏是「主机抽屉 + 会话右栏」,外屏是单栏,半折时左右并排。
- 连接过程落在会话右栏:正在连接、确认主机身份、需要凭据、失败各有自己的页面,左边的主机行同步显示状态(连接中 / 等待确认 / 需要凭据 / 失败 / 运行中)。连上之后抽屉自动收起。
- 「需要密码 / 私钥 / 口令」不再是红色的“连接失败”,而是中性的提示页,主按钮直达对应的编辑页;缺的是跳板机的凭据时,直接打开跳板机的编辑页。
- 页面切换改成新页在旧页上淡入(不再露出底色);抽屉开合时终端不再每帧整屏重画;侧栏开关跟着抽屉边缘走;主机行的色点 / 转圈 / 盾牌互相淡入淡出;滑动操作的进度在绘制阶段读取。
- 触控目标统一到 48dp(玻璃按钮、滑出的圆钮、转发 / 快照的删除钮等)。

### Added
- 终端右缘滚动条(翻到历史才出现,可拖)。
- 断线后,手机底部胶囊和内屏竖条上出现「重新连接」按钮。
- 主机行在等待密钥确认时显示盾牌与「等待确认」。
- 无障碍:主机行的「详情」、抽屉把手、搜索框都有读屏可用的操作和名称。
- 单元测试:远端路径清洗、路径折叠等。

### Fixed
- **文件传输**:远端给的目录名 / 文件名落到本地前统一清洗(`..`、反斜杠、空名),恶意或写坏的服务器不能再写出下载目录;传输收尾回调抛异常不再让后面的传输永远“排队中”;回调里不再攥着 Activity;取消传输不再丢掉共享的 SFTP 通道;「转到路径」会折叠 `.` / `..` 并支持 `~/`;重命名放在条目自己所在的目录,新建 / 重命名完成后不会把你拽回已离开的目录。
- **主机密钥**:先确认跳板机、再确认目标主机时,第二页的「信任」不再失灵;跳板机已被删时不会把它的指纹记到目标主机名下;保存失败后可以再点一次。
- **会话与凭据**:对外暴露的会话主机不再带着明文密码 / 私钥 / 口令;断线后“重新连接”不会拿回同一条已死会话;密钥库里的加锁密钥永久失效时会重建,而不是继续把新密码加密给一把解不开的密钥。
- **终端输入**:输入法一次提交的多行 / 含控制字符的文字(剪贴板条)走与菜单粘贴相同的清洗 + 括号粘贴;末尾只有一个换行的提交仍当作“打字 + 回车”;鼠标滚轮使用最新的行列数;惯性滑动进入备用屏时立刻取消;改字号但行列没变时窗口像素也会更新到服务端。
- **界面细节**:连接页第一帧不再错位;滑动行状态过期导致下一次点击不连接;编辑主机不再改变它的色点;滚动条拖动不再越过手指、不再白闪;确认页指纹卡片不再被截断;等待确认时不再同时出现“密钥待确认”标签;片段删到最后一条不再失败。

### Known
- 内屏 / 外屏的大部分改动在真机(小米折叠屏)上看过;**未在真机上验证**:断线重连按钮、换主机的页面过渡、拖拽收起抽屉后的开关位置、密钥库“永久失效”分支。
- 屏幕最左边约 40dp(抽屉收起时)是拉出抽屉的入口,点不到终端,是特意留的。
