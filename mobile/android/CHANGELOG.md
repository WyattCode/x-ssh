## [0.2.0] - 2026-11-08

第一个有版本说明的 Android 版本。界面整套重做,并经过多轮代码审查。**安装包是 debug 签名**(没有发布签名钥匙):已装 0.1.0 的设备用 `adb install -r` 可直接覆盖;换了电脑的 debug 签名则必须卸载重装,卸载会连同 Keystore 里的密钥一起删掉,已加密保存的密码要重新填。

### Changed
- 界面照 iOS「iPhone Duo」重做:终端风格、只有深色。折叠屏内屏是「主机抽屉 + 会话右栏」,外屏是单栏,半折时左右并排。
- 连接过程落在会话右栏:正在连接、确认主机身份、需要凭据、失败各有自己的页面,左边的主机行同步显示状态(连接中 / 等待确认 / 需要凭据 / 失败 / 运行中)。连上之后抽屉自动收起。
- 「需要密码 / 私钥 / 口令」不再是红色的“连接失败”,而是中性的提示页,主按钮直达对应的编辑页;缺的是跳板机的凭据时,直接打开跳板机的编辑页。
- 页面切换改成新页在旧页上淡入(不再露出底色);抽屉开合时终端不再每帧整屏重画;侧栏开关跟着抽屉边缘走;主机行的色点 / 转圈 / 盾牌互相淡入淡出;滑动操作的进度在绘制阶段读取。
- 触控目标统一到 48dp(玻璃按钮、滑出的圆钮、转发 / 快照的删除钮等)。

### Added
- 终端右缘滚动条(翻到历史才出现,可拖)。
- 断线后,手机底部胶囊和内屏竖条上出现「重新连接」按钮。
- 主机行在等待密钥确认时显示盾牌与「等待确认」。
- 无障碍:主机行的「详情」、抽屉把手、搜索框都有读屏可用的操作和名称。
- 单元测试:远端路径清洗、路径折叠等。

### Fixed
- **文件传输**:远端给的目录名 / 文件名落到本地前统一清洗(`..`、反斜杠、空名),恶意或写坏的服务器不能再写出下载目录;传输收尾回调抛异常不再让后面的传输永远“排队中”;回调里不再攥着 Activity;取消传输不再丢掉共享的 SFTP 通道;「转到路径」会折叠 `.` / `..` 并支持 `~/`;重命名放在条目自己所在的目录,新建 / 重命名完成后不会把你拽回已离开的目录。
- **主机密钥**:先确认跳板机、再确认目标主机时,第二页的「信任」不再失灵;跳板机已被删时不会把它的指纹记到目标主机名下;保存失败后可以再点一次。
- **会话与凭据**:对外暴露的会话主机不再带着明文密码 / 私钥 / 口令;断线后“重新连接”不会拿回同一条已死会话;密钥库里的加锁密钥永久失效时会重建,而不是继续把新密码加密给一把解不开的密钥。
- **终端输入**:输入法一次提交的多行 / 含控制字符的文字(剪贴板条)走与菜单粘贴相同的清洗 + 括号粘贴;末尾只有一个换行的提交仍当作“打字 + 回车”;鼠标滚轮使用最新的行列数;惯性滑动进入备用屏时立刻取消;改字号但行列没变时窗口像素也会更新到服务端。
- **界面细节**:连接页第一帧不再错位;滑动行状态过期导致下一次点击不连接;编辑主机不再改变它的色点;滚动条拖动不再越过手指、不再白闪;确认页指纹卡片不再被截断;等待确认时不再同时出现“密钥待确认”标签;片段删到最后一条不再失败。

### Known
- 内屏 / 外屏的大部分改动在真机(小米折叠屏)上看过;**未在真机上验证**:断线重连按钮、换主机的页面过渡、拖拽收起抽屉后的开关位置、密钥库“永久失效”分支。
- 屏幕最左边约 40dp(抽屉收起时)是拉出抽屉的入口,点不到终端,是特意留的。
